# Project rules
- The deck's cards and scales live in `src/components`, which carries its own `AGENTS.md` to read before changing files there.
- Trigger slider navigation hints only when the untouched marker enters view, animating the whole marker (disc and arrow) but never the saved answer; the deck keeps offscreen cards mounted, so mount-time animations would finish unseen.
- Keep additional reflection-style slides in focused components using the existing notes persistence and print flow; reuse the Health Check scale by rendering its exported `StatementScale` inside a `.risiko-page` host, and lower the field's floor when a card shares its height.
- Migrate moved answers against storage at startup and save at once; card state only persists after an edit, so the card opened first would erase what the other needs.
- Use Radix Slider for the relationship-work scale so pointer, touch and keyboard input share accessible, bounded behavior.
- Normalize workload shares with shared pure helpers and persist all changed partners in one state update; screen and print use the same normalized split to avoid mismatched totals.
- Paginate Risikofaktoren one statement per card using one shared notes namespace, so extra pages preserve existing values and follow the same print and clearing flow; the split stays parameterised so a short card drops to fewer.
- Type the Risikofaktoren statement in the big question's own voice by listing it in the shared `#root` question-font rule — a plain class rule loses to the global `#root *` typography — and let it carry only its own smaller size, stepping down on narrow phones.
- Morph shared face geometry through the current Risikofaktoren header expressions without opacity blending, so draggable markers match every scale anchor.
- Size each printed page to the printable area (not the sheet or viewport) and anchor the print container to the sheet top, so every card lands on its own page without overflow or a blank first page.
- Keep absolutely positioned card content inside the card's own content box — clamp with CSS `min()` against the container and measure the live container while dragging — so nothing can make a card horizontally scrollable.
- Health Check clicks use live bounds; keep print anchors, clear on drag. Size buttons/SVGs together overriding Button icon defaults so visible and clickable bounds match.
- Let a scale span its container edge to edge and keep the handle inside by insetting its travel by the handle's own radius, pulling the faces and end labels in by the difference — never by marginning the whole scale in, which would leave the line short of the card edges.
- Sit the Risikofaktoren smileys flush with the field's top edge and centre the rule in the room under them; the field and the names form one stack that is the face row's positioning parent. That same stack sets where the names ride: the field's floor has to reach it as a custom property (they inherit only downwards), the rise capped by the handle's own size and kept screen-only, so paper keeps its own placement.
- A slider handle's decorative contents (avatar, label) must let the pointer through, and any slider whose root ignores pointer events needs its own pointer handler on the container — reading the live handle positions, capturing the pointer and locking the handle it picked — plus touch-none and card-deck paging suppression, so a press anywhere drags the nearest handle. On a single-marker scale, leave only the marker itself to the slider and let the container's handler place it on a press anywhere else in the field, including the ends the inset track cannot reach.
- Keep both scales on one shared field height (`--risiko-field-h`): it caps the statement scale's field on screen and sets the work-split lane's height, and the lane centres its bar, dots and names on its own height with `cqh` (size containment) so print can stretch the lane without them coming loose.
- Centre the Risikofaktoren slider with a fixed scale height and an even split of the free space, closing the last pixels with a shift that halves the room between the text above and the buttons below — the scale's block, note included, stands there, clamped to the room, read on screen only, and given to the clip's own element. A note on the scale rides inside that block, screen-only, keeping its press and the card's padding as its gap.
- Pass a shared row component's label as one element: its label field lays its children side by side, so a bare fragment splits a sentence.
- A reveal's end state beats a declared font-size: settle it on the element's own token, not `inherit`.
- Intimacy uses a focused icon-rating control that maps to the existing scale answer key, preserving saved answers and the shared notes/print flow.
- Keep per-card behaviour behind an opt-in flag on the shared component so siblings stay untouched, and let print normalise rather than rewrite saved answers; derive card colours from the shared colour helpers and theme overrides, passing real values to shared fields so their contrast lightening works.
